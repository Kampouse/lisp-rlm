# ts/ — TypeScript twins of all 9 contracts

Generated by `gen_ts.py` from the SAME constants as the lisp contracts —
`pa-ts`, `pb-ts`, `pc-ts`, `pd-ts`, `pj-ts`, `n1-ts`, `n2-ts`, `splt-ts`,
`splt3-ts`. Byte-exact twins: every scenario asserts equality against the
same Isabelle pins the lisp versions use.

- **Do not hand-edit** `*/src/main.ts` — edit `../gen_ts.py` and regen.
- Build all 9: `python3 build_ts.py` (needs `near-compile` in
  `~/dev/lisp-rlm/target/release/`).
- Run the 14 TS scenarios: `python3 ../run_scen_ts.py` (state lands in
  `../ts-scen/`, fresh every run — no state.bin pitfall).
- Const names are grug: `GRID_LO`, `CELL_TOP_i`, `CELL_L_i`, `CELL_Q_i`,
  `sqp`, `price_move`, `consumed` — legend in every generated header.
